# Force Components Lab 🧠

互動式「力的分量」練習 Dashboard，適合直接放 GitHub Pages。

## 功能
- 🎯 隨機題目：Components / Resultant / Full
- 💡 答案獨立 Tab，逐步揭示解法
- 📚 互動教學：象限 + 力／角度滑桿 + 即時 Fx/Fy
- 📊 學習紀錄：完成題數、答對數、正確率、最高連勝
- 📱 手機／電腦 responsive
- 💾 localStorage 保存本機學習紀錄
- ✅ 純 HTML / CSS / JavaScript，無後端、無 API

## GitHub Pages
將 3 個網站檔案放 repo root：`index.html`、`style.css`、`app.js`。
GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save。
